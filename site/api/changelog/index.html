Changelog

Pinned versions never change. /api/latest/ moves only when a release is added here.

v0.3.0, 25 November 2026 (use this one)

Security fixes after security.b's review. v0.1.0 and v0.2.0 are superseded and should not be used for real sign-ins; they stay in place unchanged, because a released file never changes.

  • token() is off unless you pass exposeToken: true.
  • No include_granted_scopes, and a returned token wider than asked for is refused.
  • The token store and sign-in state are namespaced per module, so Drive and Chat on one origin never share a token.
  • Revoke sends the token in the request body, not the address.
  • Upload refuses a type with a line break or one that is not type/subtype.
  • Docs: what the sealed token does and does not protect, pin with a hash, safe handling of downloaded files, the sign-in return page. Still tested against a mocked Google only.

v0.2.0, 25 November 2026 (superseded)

  • The same calls as v0.1.0, now built on the shared Google base that the Chat API also uses (sign-in, token sealing, errors). DriveError now extends GoogleError.
  • Still one file with one hash: the base is inlined when the module is built.
  • Tested against a mocked Google only.

v0.1.0, 25 November 2026 (superseded)

  • Sign-in with Google's token flow (redirect, state check), the token sealed in IndexedDB for its hour.
  • List, search, get, download, export, upload, create folder, move, trash.
  • Tested against a mocked Google only. Not yet run against a real client.
